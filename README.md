# Minha Engine

Engine e editor de jogos 2D em Python/pygame, com linguagem própria (Brasa) e programação visual
(QUANDO / SE / FAÇA), modo plataforma e top-down, Loja com mais de 880 itens e modo online.

## No PC
```
pip install pygame
python minha_engine.py
```

## No celular (Android)
Baixe o **MinhaEngine.apk** na aba **Releases** deste repositório e instale.
O GitHub monta um APK novo sozinho toda vez que a engine é atualizada (aba **Actions**).
